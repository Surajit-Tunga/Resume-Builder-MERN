# Resume Builder App

A full-stack web application to easily create, edit, and export polished professional resumes.

---

## Features

- Sign up, log in, and manage multiple resumes
- Add and edit sections: Personal Info, Education, Experience, Projects, Skills, Certifications, Languages, Interests, etc.
- Real-time resume completion tracker
- Download/export resume as PDF
- Modern, responsive, and intuitive dashboard UI

---

## Getting Started

### Prerequisites

- Node.js (v14 or newer)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```
   git clone https://github.com/Surajit-Tunga/Resume-Builder-MERN.git
   cd Resume-Builder-MERN
   ```

2. **Install dependencies:**
   - Backend:
     ```
     cd backend
     npm install
     ```
   - Frontend:
     ```
     cd ../frontend
     npm install
     ```

---

## Running the Application

- **Start the backend server:**
  ```
  cd backend
  npm start
  ```

- **Start the frontend development server (in another terminal):**
  ```
  cd frontend
  npm run dev
  ```

---

## Additional Notes

- The backend server runs on [http://localhost:5000](http://localhost:5000) by default.
- The frontend app runs on [http://localhost:3000](http://localhost:3000).
- Ensure MongoDB is installed and running for backend data persistence.
- For any issues, feel free to open an issue or contribute!
